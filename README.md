# 个人主页

这是一个简洁的个人主页静态站点，包含基本信息、教育经历、论文与奖项等内容，适合部署到 GitHub Pages。

## 目录结构
- `index.html` 页面主体
- `style.css` 页面样式
- `img/` 图片资源（头像、图标、论文配图等）

## 本地预览
直接用浏览器打开 `index.html` 即可预览。

## 部署
将仓库推送到 GitHub 后，可在仓库的 GitHub Pages 设置中选择分支进行发布。

## 维护方式
- 修改内容：编辑 `index.html`
- 调整样式：编辑 `style.css`
- 替换图片：更新 `img/` 目录中的资源
